# SafeCheck — Android

The Android client of SafeCheck (one product, one shared Safety Brain, two platform
experiences). This module is a **client** of the shared SafeCheck API; it never computes the
final risk score locally. See `../docs/requirements.md`, `../docs/design.md`, `../docs/tasks.md`.

- Package / applicationId: `com.safecheck.android`
- min SDK 26, target SDK 34, Kotlin + Jetpack Compose (Material 3)
- API mode: **mock-first** (`BuildConfig.USE_MOCK_API = true`) until the shared backend is ready.

## What is implemented

This repository now contains a native Android app in `app/`.

- **SMS, text and email:** extracts every link and checks it against the live [URLhaus community API](https://urlhaus.abuse.ch/api/). A message without a URL is explicitly reported as inconclusive rather than given a made-up AI score.
- **URL and QR payloads:** live URLhaus reputation lookup; the target is never opened by the app.
- **Images and videos:** the app uploads only a user-selected file to an explicitly configured HTTPS analysis backend. This keeps model credentials and large deepfake models out of users' phones.

For semantic phishing classification and deepfake inference, set **Analysis backend URL** in the app settings. It must expose `POST /v1/analyze/text` with JSON `{ "type", "content" }` and `POST /v1/analyze/media` as multipart (`file`, `type`). Return `{ "verdict": "safe|suspicious|malicious|inconclusive", "summary": "...", "confidence": 0.0 }`.

## Prerequisites

- **JDK 17** (Android Studio bundles a compatible JBR)
- **Android SDK** (Platform 34 + build-tools)
- Android Studio Koala/Ladybug or newer recommended

## First-time setup

1. Copy `local.properties.sample` to `local.properties` and set your `sdk.dir`.
2. Open the `android/` folder in Android Studio. On first open, Android Studio will
   **generate the Gradle wrapper JAR** (`gradle/wrapper/gradle-wrapper.jar`) automatically.
   - If building from the command line without Android Studio, run once from a machine that
     has Gradle installed: `gradle wrapper --gradle-version 8.9` (regenerates the wrapper jar).
3. Let Gradle sync, then build.

## Build & test

```bash
./gradlew assembleDebug        # build the debug APK
./gradlew testDebugUnitTest    # run JVM unit tests (e.g. RedactionEngine)
```

> Note: `gradle-wrapper.jar` is a binary and is regenerated by Android Studio / `gradle wrapper`.
> All other wrapper files (`gradlew`, `gradlew.bat`, `gradle-wrapper.properties`) are present.

## Switching to the real backend (Phase 8)

Set `USE_MOCK_API` to `false` and `API_BASE_URL` to the shared API base URL in
`app/build.gradle.kts` (or via a build variant). No domain/UI changes are required —
the app selects the implementation in `di/AppContainer`.
